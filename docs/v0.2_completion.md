# MotionLab Interactive v0.2 completion

This branch intentionally combines the remaining Interactive milestones to finish
v0.2 efficiently after I0-I4 established the architecture, session store,
measurement model, local API and validated workspace shell.

## I5 — Interactive review

Verified implementation includes:

- draggable Shoulder/Hip/Knee/Ankle/Toe handles;
- letterbox-aware display-to-source pixel conversion;
- frame-local append-only manual corrections;
- reset to automatic;
- undo to previous correction or automatic;
- automatic landmark evidence preserved;
- automatic measurement results preserved;
- separate reviewed measurement cache;
- dependency-aware recalculation.

Manual review is an operator correction of visible landmark placement. It is not
by itself evidence of improved metrological or clinical accuracy.

## I6 — Results workspace

`apps/web/src/ResultsWorkspace.tsx` provides the first synchronized results view:

- knee, shank-foot and trunk curves;
- current-frame cursor;
- per-measurement mean/min/max descriptive summaries;
- frame table with time, three measurements and edited state;
- keyboard/click frame navigation back into the video workspace.

A bulk `GET /api/v1/sessions/{session_id}/frames` completion route is implemented
to avoid hundreds of independent frame requests.

The descriptive summaries are session observations only. They are not normative
or clinical thresholds.

## I7 — Export

`motionlab.session_export.export_session_bundle` produces local session-linked:

- `measurements.csv`;
- `landmarks.csv`;
- `session.json`;
- `measurements.png`;
- optional `reviewed_overlay.mp4`.

The export uses effective landmarks while retaining automatic coordinates in the
landmark and JSON records. It does not overwrite the database or frozen Core
evidence. Timing remains the session nominal-FPS indexing contract and is not
represented as exact VFR reconstruction.

A completion API route writes exports under the ignored session workspace and
registers generated artifact paths in SQLite.

## I9 — v0.2 release gate

Do not tag/release until the I8 gate is complete.

The v0.2 release documentation must state clearly:

- Core v0.1.0 remains the frozen measurement baseline;
- Interactive v0.2 adds local sessions, review, additional image-plane
  measurements, UI, results and exports;
- shank-foot is geometric, not clinical dorsiflexion;
- trunk inclination is relative to image vertical;
- camera roll and monocular 2D projection remain limitations;
- manual corrections remain auditable operator edits;
- physical stickers are visual references only and are not automatically detected;
- nominal frame timing is not an exact VFR timing claim.

## Completion branch rule

No new scope should be introduced before v0.2. Remaining work is integration,
repair, tests, private end-to-end verification and release documentation.
