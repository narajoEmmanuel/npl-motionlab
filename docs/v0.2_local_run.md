# Run MotionLab Interactive v0.2 locally

## Install

Python:

```powershell
python -m pip install -e ".[dev,interactive]"
```

Frontend:

```powershell
cd apps/web
npm ci
cd ../..
```

## Start

Backend with the final v0.2 results/export routes:

```powershell
python -m uvicorn motionlab.api.server:app --host 127.0.0.1 --port 8000
```

Frontend in a second terminal:

```powershell
cd apps/web
npm run dev
```

Open `http://127.0.0.1:5173`.

Both development services should remain loopback-only.

## Workflow

1. Enter the existing local source-video path and choose analysis side.
2. Create a session.
3. Enter matching retained Sports2D pixel TRC and provenance paths.
4. Import verified analysis.
5. Attach the same video through the browser preview control.
6. Navigate frames and review landmarks.
7. Drag a landmark only when operator review requires a visible placement correction.
8. Use Undo or Reset to Automatic when needed.
9. Use the results workspace for curves and frame-table navigation.
10. Create a local export after review.

## Important boundaries

- Browser video attachment remains local and is not uploaded.
- Automatic landmark coordinates are retained separately from manual corrections.
- Manual review does not establish clinical accuracy.
- BigToe defines the current geometric shank-foot ray.
- Trunk inclination is relative to image vertical.
- Frame time uses nominal-FPS indexing and does not establish exact VFR timing.
- Human media, TRCs, session databases and generated exports belong under ignored/private boundaries.

## Verification and export behavior

Run `python scripts/verify_v02.py` from the repository root for Python tests,
frontend tests, typecheck and build. Frontend coordinate tests require Node.js 24
(or another version supporting the configured TypeScript stripping command).

Exports publish a complete new bundle under the ignored session workspace.
Existing bundles are never overwritten. MP4 exports preserve decoded dimensions
and frame count, use nominal FPS and omit audio; odd source dimensions are rejected
rather than silently cropped. Failed exports leave no partial bundle.
