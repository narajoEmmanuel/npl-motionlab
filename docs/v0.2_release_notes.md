# NPL MotionLab Interactive v0.2 — draft release notes

Status: **release candidate ready; no tag or release has been created**.

## What v0.2 adds

MotionLab Interactive turns the frozen v0.1.0 measurement pipeline into a local
review workspace while keeping the original Core evidence boundary intact.

New post-Core capabilities include:

- local SQLite-backed MotionLab Sessions;
- verified five-role Sports2D semantic mapping for Shoulder/Hip/Knee/Ankle/BigToe;
- 2D projected knee flexion using the existing Core convention;
- 2D projected shank-foot angle;
- 2D projected trunk inclination relative to image vertical;
- local FastAPI service boundary;
- React/TypeScript desktop-browser workspace;
- local source-video preview with landmark overlays;
- frame-local manual landmark correction with immutable automatic coordinates;
- correction history, undo and reset-to-automatic;
- synchronized measurement results workspace;
- local CSV, JSON, figure and reviewed-overlay MP4 exports.

## Measurement boundaries

### Knee

The released knee convention remains:

`180 deg - included angle(Hip, Knee, Ankle)`.

### Shank-foot

The v0.2 geometric definition is `Knee -> Ankle -> BigToe`, with Ankle as vertex.
It is intentionally not labeled clinical dorsiflexion or plantarflexion.

### Trunk

The v0.2 definition compares `Hip -> Shoulder` with image vertical upward `(0,-1)`.
It is a projected global segment inclination, not spinal curvature.

## Review boundary

Automatic landmark positions remain immutable evidence. Manual edits are stored
separately and determine the effective reviewed position when active. A manual
correction can fix a visibly misplaced pose landmark, but the edit alone does not
establish greater anatomical, metrological or clinical accuracy.

Physical stickers/markers visible in a recording are operator references only;
MotionLab v0.2 does not automatically detect them.

## Timing and projection limitations

- measurements remain monocular 2D image-plane quantities;
- out-of-plane motion can affect projected angles;
- trunk inclination uses image vertical and is sensitive to camera roll;
- session frame time currently uses nominal-FPS indexing and is not an exact VFR
  reconstruction;
- browser preview seeking is a review aid and is not stronger timing evidence than
  the session/source metadata contract.

## Privacy

MotionLab Interactive is local-first. Human source media, Sports2D outputs,
review databases and exports remain under ignored/private workspace boundaries
unless the operator explicitly moves them elsewhere.

## Release gate

Publish v0.2 only after the full Python suite, frontend typecheck/build, private
end-to-end review, export verification and repository privacy audit all pass.
